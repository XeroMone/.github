## About XeroMone

XeroMone is a small Roblox game studio focused on turning ideas into playable experiences quickly, then improving them through real player feedback.

We care about games that are easy to understand, fun to replay, and polished where it matters.

## What we make

- 🎯 Competitive and skill-based experiences
- 🕹️ Quick, replayable multiplayer games
- 🧪 Experimental game concepts and mechanics
- 🔁 Games designed to evolve through updates and player feedback

## How we build

**Idea → Prototype → Playtest → Ship → Learn → Improve**

We would rather get a real game into players' hands, learn what actually works, and iterate than spend forever trying to predict the perfect game on paper.
